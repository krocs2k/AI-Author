# AI Author — Project Instructions

## Overview
AI Author is a guided book-creation wizard. Users walk through a multi-step process (Genre → Synopsis → Title/Planning → Characters → Content Creation → Marketing) powered by LLM calls. An admin panel manages users, LLM configuration, Google SSO, and usage reporting.

## Key Architecture

### Wizard (`/components/ai-author-wizard.tsx`)
- 7 steps: Genre → Synopsis → Title/Planning → Characters → Content → Cover Art → Marketing
- Cover Art step (Step 6) generates AI cover images via `/api/generate-cover`
- Story Bible context loaded for series books, passed to synopsis/character/content generation APIs
- State in `BookSession` (Prisma model) + local React state
- `?sessionId=` URL param restores saved book (wrapped in Suspense)
- Progress bar supports backward navigation (click completed steps)
- "Save" button opens `SaveBookDialog` → names book + assigns folder
- "Library" link goes to `/library`

### LLM Instrumentation (`/lib/routellm/instrumentation.ts`)
- Prompt cache: SHA-256 of (taskType + model + system + user prompt)
- Only caches deterministic tasks (`genre-analysis`, `general`); skips `content-creation`, chapters
- 7-day TTL on cache entries; hit counter for analytics
- Usage logging: every call → `LLMUsageLog` row (tokens, cost, cacheHit, duration)
- Cost calculation via `/lib/llm-pricing.ts` (public pricing approximations)

### Admin Panel (`/app/admin/page.tsx`)
- Tabs: Users | LLM Config | Google SSO | Reporting
- **Reporting tab** (`/components/admin/reporting-tab.tsx`):
  - Period selector (Week/Month/Quarter/Year)
  - Summary cards, per-model table, per-task table, per-book breakdown
  - Auto-generated cost-efficiency recommendations
  - Reset button: 10 clicks in 3 seconds + confirm dialog → wipes LLMUsageLog + PromptCache
  - API: `/api/admin/reports` (GET) + `/api/admin/reports/reset` (POST)

### Folders & Library
- `Folder` model: nested tree (self-relation `FolderTree`), belongs to User
- `BookSession` has optional `folderId` + `name`
- `/api/folders` — CRUD with cycle prevention
- `/api/sessions` — list/rename/move/delete user's books
- `/app/library/page.tsx` — folder tree sidebar + book card grid + rename/move/delete dialogs

### Prisma Naming Quirk
- `LLMConfig` model → Prisma generates `prisma.lLMConfig` (lowercase first letter of acronym)
- Same for `LLMUsageLog` → `prisma.lLMUsageLog`

### Series & Story Bible
- `Series` model: groups BookSessions with a shared `StoryBible`
- `StoryBible` model: JSON fields for characters, worldBuilding, plotArcs, timeline, themes, etc.
- Auto-created empty Story Bible when series is created
- LLM-powered Bible generation/refresh via `POST /api/series/[id]/bible`
- Manual section editing via `PUT /api/series/[id]/bible`
- Library page has Books/Series tabs; Series cards link to `/library/bible/[id]` viewer

### Image Generation
- `lib/image-generator.ts`: calls Abacus.AI RouteLLM with `modalities: ["image"]`
- Admin LLM Config has Image Model selector (pink Sparkles accent)
- Cover Art wizard step generates 2 options, user selects and saves
- IMAGE_MODELS constant lists all supported models (flux, dall-e, gemini, gpt-5.x)

## API Routes Summary
| Route | Purpose |
|-------|---------|
| `/api/session` | POST/GET/PUT single BookSession (wizard state) |
| `/api/sessions` | GET/PATCH/DELETE user's book list |
| `/api/folders` | GET/POST/PATCH/DELETE folder tree |
| `/api/analyze-genre` | Genre analysis with fallback |
| `/api/generate-synopses` | Synopsis generation (8 synopses) |
| `/api/generate-titles` | Title generation with fallback |
| `/api/generate-chapter-plan` | Genre-based chapter recommendations |
| `/api/generate-characters` | Character generation (sequential) |
| `/api/generate-content` | Multi-stage chapter/forward generation |
| `/api/generate-marketing` | Cover prompts, sales copy, back cover |
| `/api/admin/reports` | Usage analytics aggregation |
| `/api/admin/reports/reset` | Wipe usage logs + cache |
| `/api/admin/llm-config` | LLM provider/model/key management |
| `/api/admin/users` | User CRUD + approval |
| `/api/admin/google-sso` | Google SSO config |
| `/api/series` | GET/POST/PATCH/DELETE series CRUD |
| `/api/series/[id]/bible` | GET/PUT/POST Story Bible (manual edit + LLM generation) |
| `/api/generate-cover` | POST generate cover art, PATCH save selected cover |
| `/api/health` | Health check for Docker |
